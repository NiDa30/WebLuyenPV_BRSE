# Project collaboration

- Keep learner access guest/local-first. Do not add learner registration/login.
- Preserve private handoff archives/raw feedback outside the repository, public samples and frontend bundle. Do not fetch/publish Drive media or third-party media without verified rights.
- AI keys stay backend-only. Distinguish local rules, learner ratings, fixture-based AI tests and actual live-provider results. Do not claim speech pronunciation scores from STT text or convert raw exam accuracy to standardized JLPT/BJT scores.
- The user requires **every subsequent implementation report to include web feature-completion progress**. Update `docs/FEATURE_PROGRESS.md` and `docs/IMPLEMENTATION_STATUS.md` with delivered changes, remaining scope and PASS/NOT_RUN evidence. Include a concise progress summary in each final response.
- Report complete, partial, blocked and not started capabilities separately. Do not invent overall completion percentages or count a partial module as finished. Use the stable M01–M17 feature catalog for module-level progress and describe the delivered increment.
- Prefer Vietnamese for user-facing implementation reports. Continue implementation autonomously within the user's scope; do not ask repeated confirmations for routine reversible work.
